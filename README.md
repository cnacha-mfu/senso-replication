# SENSO Paper 1 replication package

This package supports the paper **"SENSO: Checking Coding-Agent Manifests Against Repository History"**
by Nacha Chondamrongkul and Jing Sun (submitted to the Journal of Software: Evolution and Process).

It holds the code, the configuration, the pre-registered plans and every result file that the paper's
numbers come from. You can check the reported numbers from the committed results without running any
model and without any paid or rate-limited API.

The checking tool itself is published separately: <https://github.com/cnacha-mfu/senso-check>.
This package keeps the in-tree copies of the tool that the experiments used.

This repository is a single snapshot with no history, taken from the authors' private working
repository `senso-framework` at commit `ac4d5039a6fdbd52445b8436ffdff69a71d07c09` (branch `jsep-tool-framing`).
The paper manuscript is not included because it is under review.

| `requirements.txt`, `experiments/paper1_ontology_manifests/wp5/requirements.txt` | Python dependencies (main environment, and the separate agent-harness environment) |

## Regenerate the results digest and the figures (no API needed)

Needs Python 3.11 or newer (tested with 3.12) and a git checkout (the digest records the commit hash).

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python experiments/paper1_ontology_manifests/scripts/make_results_digest.py
python experiments/paper1_ontology_manifests/scripts/make_paper_figures.py --skip-prose
```

- `make_results_digest.py` reads only committed result files, prints how many numbers it traced, and
  must report `0 MISSING`. It rewrites `papers/paper1/results-digest.md` and `.json`. Only the generation
  metadata (commit hash, time) differs from the committed digest. In our check of this package,
  all 9,854 traced values and the sha256 table were identical to the committed digest.
- `make_paper_figures.py` checks that every source file has the sha256 recorded in the digest and that each plotted
  value equals the digest value, then writes the figure PDFs to `figures_out/`.
  In the authors' private repository the script also checks printed numbers against the manuscript text. The
  manuscript is not distributed here, so use `--skip-prose` (a flag added in this public copy; it only turns off
  the manuscript-text checks, no numeric check changes). Without the flag the script stops and tells you to use it.
  `--out-dir` chooses the output folder.

## Re-run the pipelines (optional, needs keys and time)

Re-running is not needed to verify the numbers, and it will not reproduce them bit for bit (model endpoints change).
Do not run it into the committed result folders.

- **LLM calls** all go through the free NVIDIA NIM endpoint (`https://integrate.api.nvidia.com/v1`, `openai` SDK).
  Put keys in a `.env` file as `NVIDIA_API_KEY`, `NVIDIA_API_KEY_2`, ... (see `shared/llm_judge/nim_registry.py` and
  `shared/llm_judge/nim_models_v2.yaml`). `GITHUB_TOKEN` is needed for mining. Model IDs on NIM change over time.
- **Java** is needed for the OWL reasoners (owlready2 bundles Pellet, which needs a recent Java; HermiT is called through `wp6/hermit_worker.py`).
- **Apache Jena Fuseki** on `localhost:3030` (dataset `seo`) is needed only for the older population and manifest pipeline.
- **Agent studies** (`run_wp5.py`, `run_wp6.py`) use mini-SWE-agent in a second environment
  (`experiments/paper1_ontology_manifests/wp5/requirements.txt`). The design documents give the budgets: for example the WP6 study
  has 960 runs (about 15 hours) and the WP5 study about 1,280 runs (about 43 hours at 30 runs per hour).
- Run heavy jobs with a memory and task cap and a low worker count (4 or fewer).

Each design file in `papers/paper1/` says which script and config belongs to which study.

## Changes made for this public copy

1. `experiments/paper1_ontology_manifests/scripts/make_paper_figures.py`: added `--skip-prose` and `--out-dir`,
   and a default output folder `figures_out/` when the manuscript folder is absent. No numeric check was changed.
2. Inside 3,692 compressed agent trajectory files, API keys, the host machine's address and paths of an unrelated project
   on the same machine were replaced by `REDACTED`. No recorded hash covers these files, and no other content changed.
3. This README, `LICENSE`, `LICENSE-DATA`, `NOTICE.md` and `.gitignore` were added.

## Excluded files

- The manuscript sources and figures (`papers/paper1/*.tex`, `papers/paper1/jsep/`), all other papers, internal notes,
  other studies' code and results (`papers/jcsse2026/`, `experiments/jcsse2026/`, papers 2 to 5), Word, zip and PDF files.
- `results/real/` (the earlier journal-submission results). Some older runners (`run_real_experiments.py`,
  `run_rq4_rq5.py`, `rq4_harness.py`) and configs still point to it. They are kept for completeness and need those results regenerated.
- Two agent trajectories were left out because they contained an API key:
  `results/real_v2/wp5_pilot_mt8192/trajectories/boto__botocore-1996__A__diffusiongemma-26b-a4b-it__r1.traj.json` and
  `.../zopefoundation__Products.ZSQLMethods-47__A__diffusiongemma-26b-a4b-it__r1.traj.json`.

## Absolute paths

Some result and config files contain paths such as `/home/adtgrade/...`. They refer to the original machine.
They were left as they are, because some of these files have their content hash recorded in the digest or in run manifests.
